**Description (4000):**
GeoKeyboard lets you write Georgian without hunting for letters. Type phonetically on the QWERTY layout you already know and the keyboard turns it into proper Georgian script as you type.

saxlshi xar? → სახლში ხარ?
gamarjoba, rogor xar → გამარჯობა, როგორ ხარ

Made for Georgians abroad, and for anyone whose thumbs learned QWERTY first.

HOW IT WORKS
• Type in Latin letters — see Georgian appear live, underlined, as you go
• Press space to accept the top suggestion, or tap another candidate
• Backspace right after a correction undoes it
• Prefer real Georgian keys? Switch layouts any time with the აბგ / abc key
• Full number and symbol layers

SMART, NOT GUESSY
• Autocorrect built on a 30,000-word Georgian frequency dictionary
• Handles ambiguous spellings (t/ტ/თ, k/კ/ქ, p/პ/ფ, c/ც/წ…) by picking the real word
• Works in every app: Messages, WhatsApp, Telegram, Mail, Notes

PRIVATE BY DESIGN
• Does NOT ask for “Allow Full Access”
• No network access, no accounts, no analytics, no ads
• Nothing you type ever leaves your iPhone

FREE, WITH AN OPTIONAL ONE-TIME UPGRADE
Typing, live conversion and autocorrect are free forever.
GeoKeyboard Pro is a single purchase — no subscription — that adds next-word predictions and all future Pro features.

## App Review notes

GeoKeyboard is a custom keyboard extension for typing Georgian phonetically in Latin letters.

To test:
1. Launch the app, then Settings → General → Keyboard → Keyboards → Add New Keyboard… → GeoKeyboard.
2. Open Notes or Messages, hold the globe key and select GeoKeyboard.
3. Type `saxlshi xar` — it converts live to “სახლში ხარ”. Space accepts the top candidate.
4. The აბგ / abc key switches between Latin-conversion mode and direct Georgian letters; 123 opens numbers and symbols.

The keyboard does NOT request Full Access (RequestsOpenAccess = false) and makes no network requests. No account or login is needed.

In-app purchase: “GeoKeyboard Pro” (non-consumable) in the app's Pro tab unlocks next-word predictions shown in the suggestion bar after a word is committed. All core typing features work without it. A Restore Purchase button is on the same screen.
